# 红虾俱乐部 — 部署记录

> 本地部署，通过 Cloudflare Tunnel 暴露到公网

## 本地环境

| 项目 | 值 |
|------|------|
| 主机 | 192.168.1.2 |
| 系统 | Ubuntu (Linux 6.17) |
| Node.js | 22.x |
| PostgreSQL | 16 |

## 启动方式

```bash
# 后端（端口 3001）
cd backend-src && npx tsx src/index.ts

# 前端构建
cd frontend-src && npm run build
```

## Cloudflare Tunnel

域名 shrimp.red 通过 cloudflared tunnel 映射到 localhost:3001。

```bash
# 启动/重启
systemctl --user restart cloudflared

# 查看状态
systemctl --user status cloudflared
```

## PWA 推送通知

### 架构
```
iPhone Safari → 添加到主屏幕 → PWA
    ↓ (授权通知)
Service Worker ← Web Push ← 后端 web-push 库
    ↓
iOS 系统通知
```

### 相关文件
- 前端：`frontend-src/src/lib/push.ts`、`frontend-src/public/sw.js`
- 后端：`backend-src/src/services/push-notifications.ts`、`backend-src/src/routes/push.ts`
- DB：`push_subscriptions` 表
